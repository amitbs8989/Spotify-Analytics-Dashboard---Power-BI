# Spotify Music Analysis Dashboard 🎵

## Overview

This project is an interactive Power BI dashboard designed to analyze Spotify music data and uncover patterns in audio features, artist performance, streaming trends, and platform presence.

The dashboard helps explore what characteristics are commonly found in popular songs and how music trends have evolved over time.

---

## Objectives

* Analyze popular songs based on streaming performance.
* Explore relationships between audio features such as danceability, energy, and valence.
* Identify top-performing artists and tracks.
* Study music trends across different release years.
* Compare playlist presence across Spotify, Apple Music, and Deezer.

---

## Dashboard Features

### Key Performance Indicators (KPIs)

* Total Streams
* Total Tracks
* Total Artists
* Average BPM

### Visualizations

* Top Tracks by Streams
* Popular Artists by Streams
* Stream Trends Over Time
* Track Characteristics Comparison
* Cross-Platform Playlist Comparison
* Streams by Release Year
* Tracks by Musical Key

### Interactive Filters

* Artist Name
* Release Year
* Track Name
* Musical Mode
